# Responsive Internship Board

An accessible internship listing page built with plain HTML, CSS and JavaScript (no framework).

## Features
- Semantic HTML (header, main, form, article) with labelled inputs
- Live search + domain filter, empty state and error state
- Keyboard friendly: skip link, visible focus, Clear button returns focus to search
- Responsive: 1 column (mobile), 2 (tablet), 3 (desktop)

## Run
Open `index.html`, or run `python3 -m http.server` and visit localhost:8000.
To use the supplied JSON, save it as `data/internships.json`.
